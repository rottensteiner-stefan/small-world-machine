    Interface CameraEffect

    Interface for camera effects that can be applied to a camera. Effects modify the position and target of the camera over time, and may also drive rotation (pitch/yaw) or a post-processing screen flash.

    • merge?(other: CameraEffect): boolean

      Attempts to merge an incoming same-type effect into this one instead of it being added as a separate, independently-decaying instance (e.g. re-triggering Shake accumulates trauma into the already-active instance instead of stacking).

      Parameters

      • other: CameraEffect

        The newly requested effect of the same type.

      Returns boolean

      true if other was absorbed into this effect (caller should discard other and not add it), false to add other as a new, independent effect.
