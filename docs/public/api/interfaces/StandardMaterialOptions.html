    OptionalreflectionFresnelBlend

    reflectionFresnelBlend?: number

    How much of the planar reflection's strength depends on view angle: 0 = constant strength regardless of angle, 1 = pure Schlick Fresnel (strong only within the last few degrees before a grazing angle, effectively invisible everywhere else -- physically correct for a smooth dielectric, but reads as an on/off switch rather than a gradual falloff to a human observer). Defaults to 0.5, matching the engine's original fixed blend. Lower this for a reflection that should stay legible across a wider range of viewing angles (e.g. a puddle meant to be seen from a normal, not-perfectly-grazing camera angle).
