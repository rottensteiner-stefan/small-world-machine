    Methods

    dispose

    • dispose(): void

      Releases the CPU-side pixel data: closes an ImageBitmap, shrinks a canvas' backing store to zero and drops the references. GPU copies are owned by the renderers and are freed when the objects/materials using the texture are removed from the scene; this only frees what the texture itself holds (e.g. a procedural canvas). Call it after the scene using the texture is destroyed: a disposed texture reads as not loaded, so renderers sample their white fallback.

      Returns void
