    bindVAO

    • bindVAO(): void

      Binds this mesh's cached VAO (built lazily on first use), which restores every vertex attribute pointer in one call instead of re-issuing per-attribute GL calls every draw. The index buffer is NOT captured here -- draw() rebinds the element buffer it needs.

      Returns void
