    Class AbstractWebGLRendererAbstract

    Base class for all renderer implementations.

    Backends are expected to implement defensive rendering strategies to prevent "silent failures":

    1. Validate that all uniforms defined in a material's layout are actually present in the compiled shader.
    2. Log warnings or errors if expected data structures (e.g., WebGPU uniform blocks) are missing or misaligned.
    3. Provide fallback values or behaviors if specific features (like rounded rects) are not supported by the hardware.

    AbstractisOffscreenRenderTarget

    • get isOffscreenRenderTarget(): boolean

      True while the current render() call is targeting an offscreen RenderTarget/ RenderTargetCube (a DynamicReflectionProbe face or a PlanarReflectionNode), rather than the main camera's canvas. WebGLShadowPass uses this to skip re-rendering the directional-light cascade atlas for these secondary, differently-angled cameras -- the atlas is fit to the main camera once per frame and shared by every pass; rebuilding it from a probe's much wider, differently-positioned view clobbered it with geometry culled to that probe's frustum, which could leave nearby dynamic objects (e.g. an orbiting moon) unlit/black in the reflection.

      Returns boolean

    Protected_getWebGLTextureFastPath

    • _getWebGLTextureFastPath(tex: Texture): WebGLTexture | undefined

      Common early-exit checks _getWebGLTexture() needs regardless of WebGL1 vs. WebGL2 (whose upload paths otherwise differ -- WebGL2 additionally handles TextureArray via texImage3D). Returns the texture to use if any of these apply, or undefined if the caller should fall through to its own upload logic. A RenderTarget has no .image -- its GL texture already exists from being rendered into (populated in each renderer's own render-target bind path), so it's looked up in the cache instead of uploaded, mirroring the WebGPU renderer's identical RenderTarget handling.
