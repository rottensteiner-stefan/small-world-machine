    Staticblackbody

    • blackbody(t: number, target?: Color): Color

      Evaluates a thermal blackbody radiation color ramp from normalized temperature t in [0, 1].

      • 0.0: Deep dark red (0.6, 0.0, 0.0)
      • 0.5: Hot fiery orange (1.0, 0.38, 0.0)
      • 0.8: Golden yellow (1.0, 0.75, 0.33)
      • 1.0: Blinding thermal white (1.0, 1.0, 1.0)

      Parameters

      • t: number

        Normalized temperature in [0, 1] (clamped automatically).

      • Optionaltarget: Color

        Optional existing Color instance to mutate (avoids GC allocations).

      Returns Color

      • Defined in core/colors/Color.ts:220
