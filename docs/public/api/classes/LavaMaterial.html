    Class LavaMaterial

    Opaque, glowing molten-rock preset on FluidSurfaceMaterial -- see docs/adr/0013-unified-liquid-surface-material.md. A "flow family" sibling of OpenWaterMaterial/StylizedWaterMaterial (the "wave family"): same noise-driven flow mechanism, opaque and emissive instead of transparent and refractive.

    The noiseMap is a crack/crust mask: LOW luma = hot crack (emissive, color), HIGH luma = cooled crust (edgeColor). Stylized look: dark crust, glowing pulsing cracks, normal-mapped plates.
