# Changelog - @small-world-machine/geometry-extras

All notable changes to this package will be documented in this file.
This package adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-07

- **Added:** Initial modular release of procedural and exotic geometries.
- **Added:** Procedural surfaces: `Supershape`, `TorusKnot`, `MobiusStrip`, `Lathe`, `PlatonicSolid`, `ParametricSurface`, `FilledPolygon`.
- **Added:** Spatial partitioning and sampling algorithms: 2D/3D `VoronoiCells`, `VoronoiShardGeometry`, `PoissonDiskSample`, and `MarchingCubes` isosurface extraction.
