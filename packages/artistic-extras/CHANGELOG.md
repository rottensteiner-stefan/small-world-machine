# Changelog - @small-world-machine/artistic-extras

All notable changes to this package will be documented in this file.
This package adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-07

- **Added:** Initial modular release of artistic, stylized, and mixed-media shaders.
- **Added:** Metal relief shading and screen-space relief post-processor (`MetalReliefMaterial`, `MetalReliefScreenMaterial`, `MetalReliefPostProcessor`).
- **Added:** Palette knife impasto stroke rendering and stroke rasterization (`ImpastoStrokeMaterial`, `StrokeRaster`).
- **Added:** Artistic color grading utilities (`ArtisticColorUtils`).
