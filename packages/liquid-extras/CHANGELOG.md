# Changelog - @small-world-machine/liquid-extras

All notable changes to this package will be documented in this file.
This package adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-07

- **Added:** Initial modular release of art-directed liquid materials and droplet dynamics.
- **Added:** Procedural and stylized liquid materials: `NoirWaterMaterial`, `OilPuddleMaterial`, `OilSlickMaterial`, and `RainPuddleMaterial`.
- **Added:** Physical thin-film iridescence shading utilities.
- **Added:** Dynamic droplet surface interaction: `DropImpactSystem`, `FluidProperties`, `DropSurfaceParams`, and drop regimes.
