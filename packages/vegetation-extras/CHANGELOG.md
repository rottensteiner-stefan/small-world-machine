# Changelog - @small-world-machine/vegetation-extras

All notable changes to this package will be documented in this file.
This package adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-22

- **Added:** Initial modular release of vegetation building blocks for Small World Machine.
- **Added:** Global and local wind field simulation (`WindField`, `windShaders`).
- **Added:** Camera-centered concentric ground cover instancing (`GroundCoverSystem`, `GrassClump`).
- **Added:** Multi-species foliage look blending (`FoliageLook`, `ForestLookBlender`, `VegetationSpecies`).
- **Added:** Far-field octahedral impostor baking and rendering (`OctahedralImpostor`, `OctahedralImpostorMaterial`).
- **Added:** Terrain-following canopy shell envelopes (`CanopyShell`, `CanopyShellMaterial`).
