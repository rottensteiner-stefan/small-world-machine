# Changelog - @small-world-machine/vfx-extras

All notable changes to this package will be documented in this file.
This package adheres to [Semantic Versioning](https://semver.org/).

## [0.2.0] - 2026-11-22

- **Added:** 3D Smoothed-Particle Hydrodynamics (`SphFluidAffector`) simulation with density/pressure computation, boundary enforcement, and SPH viscosity.
- **Added:** SPH fluid particle showcase demonstration integration.

## [0.1.0] - 2026-11-07

- **Added:** Initial modular release of Small World Machine visual effects and particle systems.
- **Added:** CPU and WebGPU compute-backed particle systems (`ParticleSystem`, `GPUParticleSystem`).
- **Added:** Vector field and force affectors (`GravityAffector`, `VortexAffector`, `TurbulenceAffector`).
- **Added:** Dynamic particle light pooling (`ParticleLightPool`) and trail renderers (`ParticleTrailRenderer`).
- **Added:** Accretion disk and procedural fire systems (`AccretionDiskEmitter`, `FireSystem`).
