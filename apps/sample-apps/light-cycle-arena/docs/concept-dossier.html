LIGHT CYCLE ARENA

Ein minimalistisches Cyberpunk-Vektor-Duell auf einer 24×24-Arena. Das klassische Tron-Prinzip verschmilzt mit einer taktischen Superhot Time-Dilation-Mechanik: Die Zeit fließt nur bei gehaltener Bewegungstaste – lässt man los, friert die Arena auf 8% ein.

Raster: 24×24 Zellen (96×96 Units)
Pipeline: WebGPU / WebGL2 / WebGL1
Kamera: Orthographic Isometric
Assets: 0 KB (100% Procedural Primitives)
PostFX: Neon Bloom + Camera Flash

Design-Säulen & Kernmechaniken

⏳ "Time Moves When You Move"

Inspiriert von Superhot. Wenn der Spieler eine Richtungstaste (WASD / Pfeile) hält, laufen beide Cycles mit vollem Tempo (CYCLE_SPEED = 13). Lässt man los, interpoliert die globale Zeitskalierung via Lerp blitzschnell auf IDLE_TIME_SCALE = 0.08. Der Twitch-Reflex-Runner wird zum taktischen Routen-Schachspiel.

📐 100% Prozedurale Vektor-Ästhetik

Keine externen Bitmaps oder 3D-Modelle. Der Arena-Boden nutzt Ground, das leuchtende Gitter GridGeometry mit WireframeMaterial, und die permanenten Lichtwände werden hocheffizient über einen gemeinsamen InstancedMesh-Drawcall gerendert. Maximale Performance, null Ladezeiten.

👁️ Isometrische Orthographische Übersicht

Eine starre isometrische Kameraperspektive ohne Fluchtpunktverzerrung (OrthographicProjection + CameraStrategyType.ISOMETRIC). Das gesamte 96×96-Spielfeld bleibt zu jedem Zeitpunkt vollständig einsehbar, sodass Korridore und Sackgassen präzise vorausberechnet werden können.

Die Superhot-Zeitkrümmung

Mechanische Synchronisation

Entscheidend für die Spielbalance: Das Zeit-Dilation-Delta skaliert beide Kontrahenten gleichzeitig. Die Zyklen sind nicht relativ schneller oder langsamer, sondern die gesamte Arena hält gemeinsam den Atem an:


// Zeitinterpolierung im Render-Loop const target = roundOver ? 0 : isHoldingMove() ? 1.0 : 0.08; timeScale += (target - timeScale) * Math.min(1, deltaTime * 6.0); // Beide Cycle-Behaviors manuell getaktet player.movement.update(deltaTime * timeScale); ai.movement.update(deltaTime * timeScale); hud.update(timeScale);

Taktisches Feedback & HUD

Am unteren Bildschirmrand visualisiert ein dynamischer Neon-Balken (Hud.ts) die augenblickliche Zeitverzögerung. Leuchtendes Cyan signalisiert 100% Echtzeit, während ein Zusammensacken auf 8% dem Spieler sofortige visuelle Bestätigung gibt, dass das Feld eingefroren ist.

Grid-Architektur & Kontrahenten-KI

Diskretes Gitter & Kollisionsmatrix

Die Arena ist in 24×24 = 576 diskrete Zellen mit Kantenlänge 4.0 Units unterteilt (Gesamtgröße 96×96 Units). Sobald ein Cycle eine Zelle betritt, wird sie in ArenaGrid als belegt markiert und eine permanente Lichtwand instanziiert.


┌──────────────────────────────────────────────┐ │ RIVAL SPAWN (Top-Right) │ │ Position: [X: +36, Z: +16] Direction: [-1, 0, 0] │ │ │ │ ╔═══════════════════════════╗ │ │ ║ 576 Instanced Wall Slots ║ │ │ ║ Orthogonal 90° Junctions ║ │ │ ╚═══════════════════════════╝ │ │ │ │ PLAYER SPAWN (Bottom-Left) │ │ Position: [X: -36, Z: -16] Direction: [+1, 0, 0] │ └──────────────────────────────────────────────┘

Heuristische 1-Step-Lookahead KI

CycleAI entscheidet autonom an jeder Gitterkreuzung (onGridIntersection). Statt eines aufwendigen State-Machine-Overheads evaluiert die KI die 3 erreichbaren Richtungen (Geradeaus, Links 90°, Rechts 90°):


  • Sicherheits-Check: Besetzte Zellen (eigene Wand, Spielerwand, Außenrand) werden sofort verworfen.
  • Manhattan-Minimierung: Berechnet den Distanzgewinn zum Spieler (distBefore - distAfter).
  • Greedy Jagd: Wählt den Kurs, der die Lücke zum Spieler maximal verengt, um ihn einzukreisen.
  • Crash-Fatalismus: Sind alle 3 Wege blockiert, fährt die KI geradeaus in die Wand und detoniert.

Engine-Blueprint & Subsysteme

Subsystem / Klasse Rolle in Light Cycle Arena Technische Besonderheiten
GridMovementBehavior Orthogonale Bewegung & diskrete Turns Wird mit isActive = false gebunden und in App.update() manuell mit skaliertem deltaTime * timeScale getaktet.
InstancedMesh Permanente Lichtwand-Segmente Ein einziger Cube-Mesh-Drawcall pro Cycle für bis zu 576 Segmente. Matrizen werden on-the-fly via setMatrixAt() in den GPU-Buffer geschrieben.
BloomElement Post-Processing Neon-Glow Intensität 0.9, Threshold 0.55. Verleiht den Emissive-Materialien (Faktor 5–6) den charakteristischen Tron-Film-Look.
OrthographicProjection Verzerrungsfreie Kameraübersicht Halbhöhe ARENA_CELLS * GRID_SIZE * 0.62. Verhindert optische Fluchtverzerrungen für millimetergenaues Planen während Bullet-Time.
Camera Effects Treffer-Feedback & Screen Flash CameraEffectType.SHAKE (0.5 s, Amplitude 0.35) und CameraEffectType.FLASH (0.5 s, Intensität 0.2) bei Crash-Einschlag.
Procedural Audio Synthetische Crash-Töne Direkte WebAudio-Oszillatoren via audio.playTone(): 90 Hz Square-Wave für Spieler-Crash, 520 Hz Sawtooth für KI-Niederlage.

Steuerung & Gameplay-Guide

🎮 Steuerung

W / A / S / D oder Pfeiltasten zur Kursänderung.
Gedrückt halten: Zeit läuft mit 100%.
Loslassen: Zeitlupe / Bullet-Time (8%).
Enter: Sofortiger Runderneustart nach Crash.

⚡ Taktik: Die Falle stellen

Da die KI stur den Abstand minimiert, kann sie leicht getäuscht werden: Halte kurz an (Bullet-Time), plane einen 90°-Haken um eine bereits gezogene Wand herum und schneide der KI den Rückweg ab.

⛔ Tödliche 180°-Wenden

Ein direktes Umdrehen in die entgegengesetzte Richtung wird vom Steuerungspuffer ignoriert, um sofortige Selbstzerstörung durch Kollision mit dem eigenen Hecksegment zu verhindern.
