Showcase 44 — Instancing Measurement Rig

Real-browser measurement stand for the A2 geometry-grouping work. Not a page for eyes — a reproducible instrument that reports real WebGL2 draw calls per frame for a geometry-mix scene, with and without automatic instancing (ADR 0046).

Why

docs/research/instanced-batching-2026-10-24.md §7.1(b) asked for an in-browser measurement of a scene whose benefit comes from geometry grouping (A2), not from "consecutive identical objects". That scenario cannot be expressed by naive ADR-0046 instancing — it needs a measurement scene that intersperses geometries so only A2 can batche them — plus a way to count the real draw calls the renderer issues. This showcase is that rig.

Scene design

Geometry mix

  • Two cube geometries (1.0 / 1.7), one shared StandardMaterial.
  • Scattered in alternating insertion order (i % 2): never two equal geometries in a row → naive instancing finds nothing, A2's grouping is what merges the batch.
  • frustumCulled = false on every cube, fixed 3/4 camera → visibility cannot bias the count.

Clean draw budget

  • Ambient light only → no shadow passes.
  • No post-processing, no IBL, no sprites.
  • Counted draws = pure opaque main-pass draws of the cubes.

Instrumentation

  • Renderer pinned to WEB_GL2 (WEB_GPU draws don't go through GL entry points).
  • canvas.getContext("webgl2") returns the engine's own context → shadow drawArrays/drawElements/drawArraysInstanced/drawElementsInstanced with a tally.
  • No engine change, no new public parameter (Whack-a-Mole doctrine).

Measurement contract

  • ?inst=off — disable autoInstancing (per-object baseline, "before").
  • ?count=N (default 1600), ?frames=N (default 240).
  • 30 warm-up frames, then a sampling window; the result is emitted exactly once as MEASURE {json} to the #__measure overlay and the console.
  • Machine consumer: scripts/measure-a2-instancing.mjs.
The frame-time delta between the two legs is often small: both legs rasterize the same pixels. The crisp metric is draw calls per frame (2 vs 1600 here). A negligible frame-time delta on this pixel-limited scene is itself the expected, documented finding — exact follow-ups live in docs/research/instanced-batching-2026-10-24.md §9.1.

Runbook

  • npm run build:showcases — bake the rig into dist/.
  • node scripts/measure-a2-instancing.mjs — starts the preview server itself, measures inst=on (A2-active) and inst=off (baseline), prints both records.
