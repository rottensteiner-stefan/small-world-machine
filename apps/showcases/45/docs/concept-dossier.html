Showcase 45 – Fire VFX Lab

Practical fire for small narrative scenes: torches, a campfire, a candle. Layered like every production engine does it, built to run on WebGPU, WebGL2 and WebGL1.

Design pillars

  • Layers, not one effect: flame body, glow, embers, smoke, light, grounding, atmosphere, audio.
  • Flame as shader card: crossed vertical cards with procedural noise erosion. One draw call per flame, no overdraw storm.
  • Colour by temperature: blackbody ramp by default (core 2800 K, body 2000 K, tip 1300 K), explicit palettes for unnatural fire.
  • Stylized-indie look (ADR 0012): crisp tongues, readable silhouette, warm bloom.

  • Alt+1 / Alt+2 / Alt+3: WebGL1 / WebGL2 / WebGPU.

Architecture

Fire (planned P4, Object3D container)
 ├─ FireMaterial on createFlameCardGeometry   (P1, done)
 ├─ FlameGlowMaterial on billboard Plane      (P1, done)
 ├─ PointLight + FireLightBehavior            (P2)
 ├─ ParticleEmitter: embers / smoke           (P3)
 └─ ember bed, soot decal, audio              (P4)
