Decal Probe: Box-Projected Decals on GPU

A rendering laboratory for the engine's decal system — projected decals on floor, wall and a pedestal, normal-buffer blending, a recycling DecalPool, wet-puddle ORM probes and cross-backend parity.

Core Pillars & Technical Highlights

1. Box-Projected Decals

Decals are projectors with a box volume. A box wider than the pedestal base lands only on the floor; the pedestal's vertical sides must fade through the angle fade instead of smearing. World layout: floor, wall, pedestal, around-pedestal, normal probe, UV orientation control pair.

2. Normal-Buffer Blending

A half-transparent decal over a normal-mapped floor: the decal's strongly tilted tangent-space normal is alpha-blended with the floor normal in the normal buffer, never overwriting it. `?nb=1|0|auto` forces the normal buffer on/off (the WebGL1 bake path must omit decals cleanly).

3. PBR Probe Constellation

ORM/emissive/metallic/bump/wet probes against a shared `StandardMaterial` floor and an unlit twin — proving the decal shader reads the same channel mapping as the rest of the engine (AO, roughness, metallic, emissive, normal map) under a controlled light.

Lab Controls (query parameters)

  • Main scene: floor/wall/pedestal probes; ?spot=1 swaps the sun for a shadow-casting spot with an occluder whose shadow crosses a decal edge; ?bump=1|2 gives the floor a normal map; ?unlit=1 makes every probe decal unlit (WebGL2 normal-buffer requirement).
  • Normal buffer: ?nb=1 / ?nb=0 force it on/off, default auto; ?pp=1 enables post-processing, ?hbao=1 additionally turns on HBAO independent of the normal buffer.
  • Post-process / bake: ?bake=1 bakes every decal into a mesh before the first frame (the WebGL1 path); ?rendererType=WEB_GPU|WEB_GL2|WEB_GL1 picks the backend.
  • Lab scenes: ?pool=1 drives a DecalPool (recycling, restacking, fade; &shoot=1 for real pointer-click ray casts); ?wet=1 shows the kit's wet-puddle ORM preset against a dark-only twin; ?orm=1 the eight-step ORM/emissive/metallic probe row; ?mip=1 the mip-sharpness comparison (Plane vs. Decal) with ?mipbias=<n>.

Verification Tooling

The page is the target of npm run test:decals (scripts/check-decals.mjs) and node scripts/measure-decal-mips.mjs. Those scripts share world coordinates with the scene modules and assert on GPU readbacks — normal-buffer contents, decal pixels, pool restacking — under WebGPU, WebGL2 and WebGL1. See docs/guides/decals.md and ADR 0028 / 0029.
